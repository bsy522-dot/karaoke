===============================================================================
 StarVoice 노래방 앱 - 개발 문서 & 개선 요청 프롬프트
===============================================================================

【 프로젝트 개요 】
StarMaker(스타메이커)를 모방한 모바일 노래방 웹앱.
React JSX 단일 파일로 구현되었으며, Tone.js + Web Audio API + MediaRecorder를 활용.

===============================================================================
【 구현된 기능 상세 】
===============================================================================

1. 홈 화면
   - 노래 목록 (2000년대 한국 가요 8곡: 버즈-가시, 김범수-보고싶다, god-거짓말,
     박효신-눈의꽃, god-한발짝더, 김건모-미안하다사랑한다, SG워너비-내사람, 빠라빠빠)
   - 장르 필터 (전체 / 발라드 / 댄스)
   - 검색 기능 (노래 제목 or 가수명)
   - 각 곡에 난이도 표시 (쉬움/보통/어려움), 재생시간 표시

2. 노래 부르기 화면 (Singing Screen)
   - 실시간 가사 표시: 노래방처럼 왼쪽→오른쪽으로 핑크→골드 그라데이션 색칠 효과
     이전 가사(흐림) / 현재 가사(하이라이트) / 다음 가사(미리보기) 3줄 구조
   - 음정 시각화 (PitchViz 컴포넌트):
     * Canvas 기반 실시간 렌더링
     * 초록색 블록: 불러야 할 목표 음정이 오른쪽에서 스크롤되며 다가옴
     * 핑크색 라인: 사용자 음성의 실시간 높낮이 (높으면 위, 낮으면 아래)
     * 목표↔사용자 음정 사이 점선 가이드
     * 현재 위치에 글로우 도트 + 음이름 표시
   - 점수 시스템:
     * PERFECT (±1 반음) = 10점 + 콤보 보너스
     * GOOD (±2 반음) = 7점
     * OK (±3 반음) = 4점
     * MISS = 0점 + 콤보 리셋
     * 콤보 보너스: 연속 성공 시 1.5%씩 추가
   - 판정 표시: PERFECT ✨ / GOOD 👍 / OK / MISS 실시간 표시
   - 콤보 카운터: 3콤보 이상부터 표시, 색상 변화 (초록→핑크→골드)
   - 프로그레스 바: 현재 진행 시간 / 전체 시간
   - 녹음 상태 표시: 마이크 모드일 때 "🔴 녹음중" + 빨간 점 깜빡임

3. 오디오 시스템 (Tone.js)
   - 가이드 멜로디: Triangle 신스로 목표 음정 연주
   - 배경 코드: Sine 신스로 곡의 키에 맞는 3화음 (근음+3도+5도)
   - 드럼 비트: MembraneSynth(킥) + NoiseSynth(하이햇), 곡 BPM에 동기화
   - 노래 종료 시 모든 오디오 자동 정리 (dispose)

4. 음정 감지 (Pitch Detection)
   - 마이크 모드: Web Audio API → AnalyserNode → Autocorrelation 알고리즘
     * FFT size 4096, RMS threshold 0.008
     * 80Hz~1200Hz 범위 감지 (사람 음성 범위)
   - 시뮬레이션 모드: 마이크 접근 불가 시 자동 전환
     * 목표 음정 기반 랜덤 시뮬레이션 (45% perfect, 25% ±1, 15% ±1, 7% ±2, 8% miss)

5. 녹음 & 재생 (MediaRecorder API)
   - 마이크 스트림을 MediaRecorder로 동시 녹음 (audio/webm;codecs=opus)
   - 노래 종료 시 Blob → ObjectURL 생성
   - 결과 화면에서 바로 재생 가능 (AudioPlayer 컴포넌트)
   - 프로필 > 최근 기록에서도 과거 녹음 재생 가능
   - 시뮬레이션 모드에서는 "녹음 없음" 표시

6. 결과 화면 (Result Screen)
   - ScoreRing: SVG 원형 점수 게이지 (애니메이션)
   - 등급: SSS(95+) / SS(90+) / S(85+) / A(80+) / B(70+) / C(60+) / D
   - Perfect/Good/OK/Miss 통계
   - 최대 콤보 표시
   - 녹음 재생 버튼
   - 다시 부르기 / 홈으로 버튼

7. 커뮤니티 화면
   - 다른 사용자들의 노래 기록 피드 (더미 데이터)
   - 사용자별 아바타, 뱃지, 점수, 좋아요, 댓글 수
   - 좋아요 토글 기능

8. 프로필 화면
   - 부른 곡 수 / 평균 점수 / 최고 점수 통계
   - 최근 기록 리스트
   - 각 기록에서 녹음 재생 가능

9. 가사 시스템
   - 8곡 전부 오리지널 한국어 가사 (저작권 문제 없음)
   - 시간 동기화 ({time, text} 배열)
   - 각 곡의 원곡 분위기에 맞게 작사

【 기술 스택 】
===============================================================================
- React (useState, useEffect, useRef, useCallback)

- Canvas API (음정 시각화)

---프롬프트 시작---

첨부한 karaoke-app.jsx 파일은 StarMaker를 모방한 노래방 웹앱이야.
React + Tone.js + Web Audio API + MediaRecorder로 구현되어 있어.

현재 구현된 기능:
- 2000년대 한국 가요 8곡 (버즈, 김범수, god, 박효신, SG워너비 등)
- 실시간 음정 감지 (마이크 autocorrelation / 시뮬레이션 fallback)
- Canvas 기반 음정 높낮이 시각화 (목표 음정 블록 + 사용자 음성 라인)
- Tone.js 가이드 멜로디 + 배경 코드 + 드럼 비트
- 노래방 스타일 가사 색칠 애니메이션
- MediaRecorder 녹음 + 결과/프로필에서 재생
- 점수/콤보/등급 시스템
- 커뮤니티 피드 + 프로필

이 앱을 더 완벽하게 만들어줘. 아래 사항들을 개선/추가해줘:

1. 【음정 시각화 개선】
   - 목표 음정 블록이 실제 노래방 기계처럼 더 자연스럽게 스크롤되게
   - 사용자 음성 라인의 떨림을 스무딩 처리해서 부드럽게
   - 음정이 맞을 때 파티클 이펙트 or 반짝임 효과 추가

2. 【오디오 개선】
   - 곡마다 다른 악기/음색 사용 (발라드는 피아노, 댄스는 신스)
   - 베이스 라인 추가
   - 비트 패턴을 곡마다 다르게 (발라드 4/4 느린 비트, 댄스 빠른 비트)

3. 【녹음 기능 강화】
   - 녹음된 음성에 리버브/에코 효과 적용 옵션
   - 녹음 파일 다운로드 기능

4. 【게임성 강화】
   - PERFECT 연속 시 화면 이펙트 (불꽃, 별똥별 등)
   - 곡 클리어 조건 (예: 60점 이상이면 클리어)
   - 난이도별 스코어 보정

5. 【UI/UX 개선】
   - 노래 선택 시 미리듣기 (3초 정도)
   - 노래 시작 전 3, 2, 1 카운트다운
   - 결과 화면에서 점수에 따른 리액션 애니메이션
   - 스크롤 시 부드러운 전환 효과

6. 【소셜 기능】
   - 점수 공유 카드 생성 (이미지로 저장 가능)
   - 랭킹 보드 (곡별 최고 점수)

7. 【곡 추가】
   - 2000년대 노래 더 추가해줘 (MC몽, 빅뱅, 동방신기, SS501, 원더걸스 등)
   - 각 곡에 맞는 오리지널 가사도 같이

Galaxy Flip 같은 세로로 긴 화면에 최적화해줘.
모바일 터치 인터렉션도 신경 써줘.
단일 JSX 파일로 유지해줘.
